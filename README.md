## Новое в этой сборке

- Classic bishop обновлён в сторону силуэта с предоставленного пользователем образца.
- Онлайн: Быстрая игра, Блиц, Играть с другом.
- Комната друга: время, без времени, рейтинг/без рейтинга, отмена хода через rewarded video + согласие соперника.
- Переподключение онлайн-партии — 60 секунд.
- Мобильный чат и панель матча.
- 30 тактических задач + расширенное обучение.
- Яндекс SDK подключён до игрового кода.
- Автоопределение языка на старте через `environment.i18n.lang` с fallback на русский.
- Guest mode без авторизации.
- Яндекс ID только по осознанной кнопке и с описанием преимуществ.
- Облачное сохранение для авторизованного пользователя.
- Лидерборд Elo через SDK.
- Звуки через Web Audio API.
- `game_api_pause` / `game_api_resume` для остановки звука и игрового процесса.
- `LoadingAPI.ready()` вызывается после запуска интерфейса.

## Важная настройка в Консоли Яндекс Игр

Создайте два лидерборда в Консоли Яндекс Игр:
- `elo` — рейтинг Elo;

Если в черновике заявлен только русский язык, текущий UI корректно использует русский как fallback для неподдерживаемых языков. Если нужно заявить English/другие языки, потребуется полный перевод интерфейса.
